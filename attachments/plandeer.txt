The agent must remember, store, and execute the following configuration arrays, routing parameters, and execution instructions for specific Fourthwall catalog categories:

#### A. APPAREL (Shaka Wear Tees, Shaka Wear Hoodies, Bella+Canvas Shorts)
- Primary App Focus: PhotoCraft & EffectCraft
- Programmatic Action: 
  1. Extract color channels from SVG; enforce strict sRGB target matrices.
  2. PhotoCraft applies alpha-mask canvas trimming to clear unutilized transparent margins.
  3. EffectCraft applies a procedural "distressed halftone vintage screenprint" overlay onto the asset.
- AI Agent Execution Instructions: 
  - Execute headless call with arguments: `--target-dpi 300 --color-profile srgb --dimensions 14x16in`.

- Headless API/CLI Driving Reference:
  `photocraft-cli --input [svg_source] --trim-alpha true --out-dir /tmp/apparel/`
  `effectcraft-cli --input /tmp/apparel/trimmed.png --filter "vintage_screen_300" --output /opt/pod-pipeline/build/apparel_final.png`

#### B. CUSTOM KNITWEAR (Knit Crewnecks, Knit Cardigans, Knit Vests)
- Primary App Focus: DesignCraft & VectorCraft
- Programmatic Action: 
  1. VectorCraft isolates and reduces colors down to a strict maximum palette of 4-6 distinct safe factory yarn colors.
  2. DesignCraft converts continuous geometric paths into discrete pixel-to-stitch spatial coordinate grids.
  3. Formats matrix outputs into uncompressed, row-by-row indexed BMP arrays ensuring hard edge boundaries.
- AI Agent Execution Instructions:
  - Enforce absolute grid alignment arrays. Throw an exception loop if any pixel contains aliased gradient transparency (must be 100% opaque thread colors).
  - Scale file array dimensions to mirror the exact factory row-and-stitch count parameters.
- Headless API/CLI Driving Reference:
  `designcraft-cli --mode "stitch_matrix" --palette-limit 6 --grid-scale [factory_template_spec] --output /opt/pod-pipeline/build/knitwear_final.bmp`

#### C. ACCESSORIES & ACCESSORY TEMPLATES (AS Colour Caps, Crossbody Bags, Under Armour Backpacks)
- Primary App Focus: DesignCraft
- Programmatic Action:
  1. Downloads specific multi-layered PDF/SVG template bounds from Fourthwall's product matrix schemas.
  2. Dynamically calculates and centers the design within safe graphic printable zones.
  3. Auto-generates matching physical text parameters (e.g., custom interior brand tags or product care instructions).
- AI Agent Execution Instructions:
  - Track safe zone margins via object bounding boxes (`bbox`). 
  - Auto-adjust tracking and kerning metrics if typography length exceeds the accessory canvas boundary limits.
- Headless API/CLI Driving Reference:
  `designcraft-cli --template "fourthwall_crossbody_v1" --layer "artwork" --embed [source_svg] --layer "care_label" --text "100% Polyester" --output /opt/pod-pipeline/build/accessory_final.pdf`

#### D. ODD/3D TEMPLATES (Sublimation Socks, Arctic Zone Tumblers)
- Primary App Focus: DesignCraft & EffectCraft
- Programmatic Action:
  1. DesignCraft builds an automated tiling macro array to wrap artwork seamlessly around non-standard printable items.
  2. EffectCraft calculates 3D texture mapping deformations to preview distortion anomalies on cylindrical/tapered surfaces before exporting.
- AI Agent Execution Instructions:
  - Generate full bleed layouts (`--bleed 0.25in`) for sublimation sock assets to guarantee 100% heel-to-toe ink coverage.

- Headless API/CLI Driving Reference:
  `designcraft-cli --mode "wrap_tile" --bleed 0.25 --input [source_svg] --output /tmp/odd/tiled.pdf`
  `effectcraft-cli --cylinder-taper --input /tmp/odd/tiled.pdf --output /opt/pod-pipeline/build/odd_final.pdf`

#### E. STATIONERY & PROMOTIONS (Karst Bound Notebooks, Custom Branded Packing Slips)
- Primary App Focus: DesignCraft & FilmCraft
- Programmatic Action:
  1. DesignCraft locks layouts down to a hyper-precise 300+ DPI CMYK print canvas matrix for vector covers.

- AI Agent Execution Instructions:

- Headless API/CLI Driving Reference:
  `designcraft-cli --input "notebook_cover_template" --variable-data "order_id" --output /opt/pod-pipeline/build/print_ready_stationery.pdf`
